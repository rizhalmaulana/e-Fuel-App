# Plan: Generate Static Table10000 di calibration_helper.dart

## Goal
Mengreplace sparse table10000 dengan data lengkap (1800 entries) dari data yang user berikan.

## Data yang akan digunakan
- mm_full: 0 → 1799 (1800 entries)
- liter: 0 → ~10,761 (format Indonesia: koma desimal, titik ribuan)

## Steps

### 1. Parse & Convert Data
- Konversi format Indonesia (koma desimal, titik ribuan) ke format double Dart
- Contoh: `5.965,70` → `5965.70`, `0,209` → `0.209`

### 2. Generate Static Map
- BuatMap<int, double> table10000 dengan 1800 entries
- Format: `{ 0: 0.0, 1: 0.209, 2: 0.591, ... }`

### 3. Update File
- Replace Map table10000 yang ada di `lib/helpers/calibration_helper.dart`
- Pertahankan fungsi getHeightByVolume dan getVolumeByHeight

## Output
File `lib/helpers/calibration_helper.dart` dengan table10000 lengkap 1800 entries.
